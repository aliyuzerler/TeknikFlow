# Skill: DevOps and Release

- Maintain local Docker Compose, CI, env templates and health checks.
- Pin dependencies via lockfile; scan dependencies and container images.
- Use staging with anonymized seed data.
- Migrations must support expand/contract and rollback/forward fix strategy.
- Monitor latency, errors, queue, sync and billing events.
- Verify backups and restore drills.
- Release only after test gates and rollback instructions are ready.
