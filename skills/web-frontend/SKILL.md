# Skill: Web Frontend

- Use Next.js App Router with server/client boundary chosen intentionally.
- Prefer server components for read-only data and client components for interaction.
- Keep forms schema-aligned with API contracts; show field errors.
- Use query cache with explicit invalidation and permission-aware cache scope.
- Use design tokens and shared UI package; build accessible Radix-based components.
- Create Storybook story and interaction test for new shared component.
- Add Playwright coverage for changed workflows and role boundaries.
- Handle loading, error, empty, stale, offline and unauthorized states.
