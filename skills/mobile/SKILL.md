# Skill: React Native Field App

- Design for fast one-handed use in daylight, gloves/rough conditions where practical.
- Use large actions, plain labels, minimal text entry and safe autosave.
- Store access token securely; store only assigned, minimal data in SQLite.
- Persist drafts/outbox transactionally and sync idempotently.
- GPS only on explicit visible job milestone action; provide manual fallback.
- Use native permission prompts at the moment feature is requested.
- Test app background/kill/restart, no network, low storage and denied permissions.
- Use RNTL for component behavior and Maestro for critical device journeys.
