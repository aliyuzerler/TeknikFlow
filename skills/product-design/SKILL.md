# Skill: Product Design and UX

1. Read Product Requirements, Screen Map and Design System.
2. Identify persona, top task, context, frequency and failure conditions before designing.
3. Map information architecture and user flows; do not start from isolated screens.
4. Define page hierarchy, table columns, filters, actions and state variants.
5. Create responsive web and field-ready mobile patterns.
6. Create Storybook stories for shared components and variants.
7. Review accessibility, keyboard, touch target, empty/loading/error/offline states.
8. Compare the implementation against design preview and token constraints; record deviations.

Deliverables: flow notes, stories, responsive UI, interaction tests and updated docs.
