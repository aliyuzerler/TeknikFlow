# Skill: Security Review

- Threat model feature changes for tenant isolation, IDOR, XSS, CSRF, SSRF, injection, file abuse, replay, privilege escalation and PII leakage.
- Verify authorization at endpoint and object level.
- Add cross-tenant test fixtures.
- Review token/session lifecycle, webhook signature verification and idempotency.
- Review logs, error messages, export paths and signed URLs.
- Record findings with severity, exploit precondition and remediation.
- Do not claim legal or security certification based only on automated scans.
