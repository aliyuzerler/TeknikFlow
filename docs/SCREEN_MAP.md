# Screen Map

## Web — tenant workspace
- `/app/overview` operational dashboard
- `/app/requests` request inbox
- `/app/work-orders` list/kanban
- `/app/work-orders/[id]` work order detail/timeline
- `/app/dispatch` calendar/dispatch board
- `/app/calendar` team availability
- `/app/customers` customer directory
- `/app/customers/[id]` customer profile and service history
- `/app/assets` equipment registry
- `/app/assets/[id]` asset detail/maintenance timeline
- `/app/maintenance` plans and due items
- `/app/inventory` stock overview
- `/app/inventory/items`, `/warehouses`, `/movements`, `/purchase-orders`
- `/app/team` technicians, teams, skills, availability
- `/app/reports` operational analytics
- `/app/quotes`, `/app/expenses`, `/app/documents`
- `/app/settings/company`, `/branches`, `/roles`, `/integrations`, `/billing`, `/audit`

## Customer portal
- `/portal` overview
- `/portal/requests/new`
- `/portal/requests/[id]`
- `/portal/assets`
- `/portal/quotes/[id]`
- `/portal/reports/[id]`
- `/portal/profile`

## Platform admin
- `/platform/tenants`, `/platform/tenants/[id]`
- `/platform/plans`, `/platform/subscriptions`, `/platform/usage`
- `/platform/support-access`, `/platform/audit`, `/platform/health`

## Mobile — field technician
- Authentication/onboarding
- Today / My Jobs
- Job detail and timeline
- Navigation / location action
- Checklist
- Work notes and labor
- Parts used / vehicle stock
- Camera/gallery attachment queue
- Customer signature / report preview
- Offline queue / conflict resolution
- Notifications / profile / sync status
