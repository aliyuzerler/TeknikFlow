# Tasarım önizlemeleri

- `preview.html`: operasyon genel bakış dashboard'u.
- `dispatch-board.html`: iş emirlerini atama ve saha ekiplerini planlama panosu.
- `work-order-detail.html`: müşteri, ekipman, teknisyen, SLA, zaman çizelgesi, belge ve parça bilgilerini birleştiren iş emri ekranı.
- `mobile-preview.html`: React Native saha teknisyeni ana ekranı için mobil konsept.
- `tokens.css`: renk, tipografi, radius, boşluk ve gölge tokenları.

Örnek veriler kurgusaldır. HTML dosyaları görsel referanstır; final web uygulaması Next.js bileşenleriyle, mobil uygulama ise React Native bileşenleriyle yeniden uygulanmalıdır.
